- ذخیره‌سازی inventoryهای Gold و پوشهٔ سرورهای سالم از snapshot فایل اتمیک و بازیابی نسخهٔ پشتیبان استفاده می‌کند. ظرفیت پوشهٔ سرورهای سالم طبق درخواست محصول 50,000 است.
- Fragment برای مسیرهای TLS/REALITY به outboundهای مربوط متصل می‌شود و با خاموش‌شدن تنظیم، ارجاع‌های قدیمی پاک می‌شوند.
