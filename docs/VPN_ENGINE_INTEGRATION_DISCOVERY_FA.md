# KING VPN — محدوده رسمی یکپارچه‌سازی ۱۲ فناوری

**شاخه:** `feature/king-multi-network-engines`  
**محدوده مصوب:** فقط ۱۲ فناوری زیر. هر فناوری خارج از این فهرست، خارج از محدوده این پروژه است.

## فهرست رسمی

| فناوری | نقش | وضعیت فعلی/مسیر کار |
|---|---|---|
| Xray | VPN تمام‌دستگاه | موتور موجود؛ مسیر فعلی باید حفظ شود و هیچ جایگزینی نمایشی پذیرفته نیست. |
| Hysteria 2 | VPN تمام‌دستگاه | هسته مستقل QUIC؛ نیازمند adapter اندروید و مالکیت انحصاری TUN. |
| sing-box | موتور چندپروتکلی | نیازمند نسخه pin‌شده، بررسی مجوز اجزا و adapter اندروید. |
| nthLink / Leaf | موتور/چارچوب VPN | نیازمند backend و پیاده‌سازی کامل توابع اتصال و lifecycle. |
| Shroudly | انتقال محلی / ضد DPI | ماژول محلی؛ با VPN سرور مستقل اشتباه گرفته نشود. |
| ByeDPI | انتقال محلی / ضد DPI | باید با مالکیت TUN مشترک سازگار شود. |
| PowerTunnel | پراکسی محلی / ضد DPI | باید به‌صورت transport محلی و بدون VPNService دوم بررسی شود. |
| AmneziaWG | VPN تمام‌دستگاه | پروتکل مبتنی بر WireGuard؛ نیازمند core و تنظیمات سازگار AWG. |
| OpenVPN | VPN تمام‌دستگاه | نیازمند runtime واقعی، مدیریت گواهی/اعتبارنامه و TUN adapter. |
| Shadowsocks | پراکسی رمزنگاری‌شده با TUN | نیازمند core قابل‌استفاده و adapter تمام‌دستگاه. |
| OpenConnect | VPN تمام‌دستگاه | نیازمند libopenconnect، JNI/NDK و gateway سازگار. |
| WireGuard | VPN تمام‌دستگاه | مسیر رسمی embedding بررسی شده؛ adapter اجرایی KING و handoff امن TUN لازم است. |

## الزامات معماری و پذیرش

1. مسیر Xray/V2Ray و همه قابلیت‌های موجود حفظ شوند.
2. فقط یک Android `VpnService` مالک TUN باشد؛ تعویض موتور پس از تأیید توقف و آزادشدن TUN انجام شود.
3. parser، فهرست منبع یا ثبت در کاتالوگ به‌تنهایی به معنی موتور عملیاتی نیست.
4. هر موتور باید adapter واقعی، مدیریت خطا و توقف، بررسی سلامت data-plane و آزمون IPv4/IPv6/DNS داشته باشد.
5. منابع کانفیگ هر موتور باید با قالب پروتکل همان موتور سازگار باشند؛ ورودی‌های نامرتبط حذف یا به موتور دیگر نسبت داده نشوند.
6. هر تغییر عمده سه بار بازبینی شود: معماری و lifecycle؛ امنیت و مجوز؛ تست، تحلیل ایستا و build اندروید.
7. هر قابلیت جدید خارج از فهرست ۱۲تایی، بدون درخواست صریح کاربر به پروژه اضافه نشود.

## وضعیت صداقت فنی

فقط Xray در کاتالوگ فعلی وضعیت `integrated` دارد. هیچ موتور دیگری تا زمان build موفق، آزمون adapter و اثبات عبور واقعی ترافیک، عملیاتی اعلام نمی‌شود.
