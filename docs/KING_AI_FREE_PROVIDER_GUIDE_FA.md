# راهنمای کامل King VPN و King AI

تاریخ بازبینی سهمیه‌ها: ۲۱ نوامبر ۲۰۲۶

## نمای کلی پروژه

King VPN یک برنامه اندرویدی Flutter/Dart برای مدیریت اتصال VPN است. مسیر اتصال موجود و هسته Xray/V2Ray حفظ می‌شود. اولویت پروژه، اتصال پایدار در شبکه داخلی/ملی و اینترنت جهانی، تشخیص واقعی عبور ترافیک، پشتیبانی IPv4 و IPv6، DNS، مسیریابی، مدیریت هسته، بازیابی اتصال و امنیت است.

### ۱. خلبان هوشمند شبکه (VPN Smart Pilot)

خلبان شبکه بخشی از خود برنامه است و برای تصمیم‌های حیاتی VPN به API خارجی وابسته نیست. شواهد مسیر داخلی و جهانی را جدا نگه می‌دارد، نمونه‌های مستقل و بررسی TLS را می‌سنجد و در صورت ناکافی یا متناقض بودن شواهد، استراتژی فعلی را حفظ می‌کند. APIهای ابری نباید انتخاب هسته، تغییر مسیر، شروع/توقف VPN، تشخیص سلامت تونل یا failover را کنترل کنند.

### ۲. مغز محلی King AI

مدل Qwen محلی روی گوشی اجرا می‌شود و مسیر پایه برای گفت‌وگو و استفاده آفلاین است. حافظه مکالمه در Android Secure Storage نگهداری می‌شود. آماده‌بودن مدل محلی به حافظه و توان دستگاه وابسته است.

### ۳. خلبان ارائه‌دهندگان هوش مصنوعی (AI Provider Pilot)

این خلبان از VPN Smart Pilot جداست. برای گفت‌وگوی عمومی، نوع درخواست را تشخیص می‌دهد، ارائه‌دهندگان دارای کلید را به ترتیب اولویت امتحان می‌کند و در صورت محدودیت سهمیه، خطای سرویس یا نبود ظرفیت، سراغ ارائه‌دهنده بعدی می‌رود. اگر هیچ سرویس ابری پاسخ ندهد، به مدل محلی برمی‌گردد.

در نسخه فعلی، اتصال ارائه‌دهندگان برای **گفت‌وگوی متنی** است. این اتصال به‌تنهایی تولید یا ویرایش تصویر، تدوین ویدئو، دوبله، یا اجرای ابزار روی فایل‌های دستگاه را فراهم نمی‌کند. برخی مدل‌های چندرسانه‌ای ورودی تصویر/صوت/ویدئو را تحلیل می‌کنند، اما این با تولید یا ویرایش خروجی چندرسانه‌ای یکی نیست.

## ارائه‌دهندگان رایگان قابل تنظیم

هیچ‌کدام نامحدود نیستند. فقط مدل‌ها و مسیرهایی که ارائه‌دهنده در همان لحظه به‌عنوان رایگان عرضه می‌کند انتخاب شوند؛ تغییر تعرفه و محدودیت‌ها ممکن است.

| ارائه‌دهنده | مدل/مسیر پیش‌فرض در این پیاده‌سازی | محدودیت مهم |
|---|---|---|
| Google Gemini | `gemini-2.5-flash-lite` | سهمیه رایگان برای مدل مشخص؛ داده‌های Free Tier ممکن است برای بهبود محصولات Google استفاده شود. تولید تصویر Gemini API رایگان فرض نشده است. |
| Groq | `openai/gpt-oss-120b` | طرح رایگان دارای سقف درخواست/توکن است؛ سقف دقیق در صفحه Limits حساب نمایش داده می‌شود. |
| Mistral | `mistral-small-latest` | دسترسی API و سقف‌های Free در La Plateforme ممکن است بر اساس حساب/مدل متفاوت باشد. |
| OpenRouter | `openrouter/free` | فقط مسیریابی به مدل‌های رایگان؛ ۲۰ درخواست در دقیقه و ۵۰ درخواست در روز برای مدل‌های `:free` طبق صفحه رسمی جاری. |
| Cloudflare Workers AI | `@cf/google/gemma-4-26b-a4b-it` | سهمیه Workers Free برابر ۱۰٬۰۰۰ Neurons در روز؛ برخی مدل‌ها به طرح پولی نیاز دارند. |

منابع رسمی برای بررسی مجدد:
- Gemini: https://ai.google.dev/gemini-api/docs/pricing
- Groq: https://console.groq.com/docs/rate-limits
- Mistral: https://mistral.ai/pricing/ و https://docs.mistral.ai/
- OpenRouter: https://openrouter.ai/collections/free-models/ و https://openrouter.ai/pricing
- Cloudflare: https://developers.cloudflare.com/workers-ai/platform/pricing/ و https://developers.cloudflare.com/workers-ai/models/

Cohere trial key و اعتبارهای آزمایشی یک‌باره در این فهرست قرار نگرفته‌اند؛ چون معیار پروژه رایگانِ قابل‌استفاده با سهمیه پایدار است، نه اعتبار آزمایشی موقت. NVIDIA NIM نیز تا وقتی سهمیه رایگان و شرایط بدون پرداخت آن برای مدل مورد استفاده به‌طور قابل اتکا مشخص نباشد، به‌صورت پیش‌فرض فعال نمی‌شود.

## کلیدها را کجا وارد کنیم؟

در خود برنامه، وارد صفحه **گفت‌وگوی آزاد با کینگ** شو. درست زیر کادر نوشتن پیام، بخش **«راهنمای کامل King VPN و King AI»** را باز کن. کلید هر سرویس را در کادر مخصوص همان سرویس وارد کن و دکمه **«ذخیره امن کلیدها»** را بزن.

- Gemini: کلید را از Google AI Studio بخش Get API key بگیر.
- Groq: کلید را از Groq Console → API Keys بگیر.
- Mistral: کلید را از Mistral La Plateforme → API keys بگیر.
- OpenRouter: کلید را از OpenRouter → Keys بگیر. خلبان از مسیر `openrouter/free` استفاده می‌کند.
- Cloudflare: یک API Token با مجوز لازم Workers AI بساز و Account ID حساب را هم در کادر جداگانه وارد کن.

پس از ذخیره، کادرها خالی می‌شوند و وضعیت «کلید ذخیره شده» نمایش داده می‌شود. کلیدها در Android Secure Storage ذخیره می‌شوند. آن‌ها را در چت، سورس Dart، فایل تنظیمات عمومی، APK یا GitHub قرار نده.

### فعال‌کردن استفاده ابری

گزینه **«اجازه استفاده از ارائه‌دهندگان ابری رایگان»** به‌صورت پیش‌فرض خاموش است. با روشن‌کردن آن، متن پیام‌های بعدی به ارائه‌دهنده‌ای که خلبان انتخاب می‌کند ارسال می‌شود. با خاموش‌کردن آن، برنامه فقط از مدل محلی استفاده می‌کند. کلیدهای ذخیره‌شده به‌تنهایی باعث ارسال خودکار اطلاعات نمی‌شوند.

### حریم خصوصی

- هیچ رمز، API Key، توکن GitHub، کانفیگ خصوصی VPN یا اطلاعات محرمانه را برای سرویس ابری ارسال نکن.
- Free Tier Gemini ممکن است داده‌های ورودی/خروجی را برای بهبود محصولات Google استفاده کند؛ قبل از ارسال داده حساس، شرایط جاری Google را بررسی کن.
- کلیدها فقط در Android Secure Storage نگهداری شوند و در گزارش‌ها یا پیام خطا چاپ نشوند.
- در این نسخه، پیام متنی کاربر به ارائه‌دهنده ابری فرستاده می‌شود؛ تاریخچه مکالمه، وضعیت شبکه و داده‌های تشخیصی VPN به‌صورت خودکار برای این ارائه‌دهندگان ارسال نمی‌شود.

## امنیت توسعه و دسترسی مالک

خلبان ارائه‌دهندگان فقط پاسخ متنی تولید می‌کند و مجوز نوشتن روی مخزن GitHub یا تغییر تنظیمات VPN ندارد. تغییر سورس، افزودن قابلیت به مخزن و ساخت Pull Request فقط از مسیر توسعه‌دهنده و پس از احراز هویت مالک مجاز است. هر تغییر باید در شاخه مستقل، با تست و تحلیل ایستا و سپس Pull Request قابل بازبینی ارائه شود؛ ادغام خودکار در شاخه اصلی فعال نیست.

## محدودیت‌های فعلی و مسیر توسعه

- APIهای بالا در این نسخه برای گفت‌وگوی متنی یکپارچه شده‌اند.
- تحلیل تصویر/ویدئو و تولید/ویرایش تصویر باید با مدل‌های رایگانِ دارای قابلیت مشخص و سهمیه واقعی، جداگانه پیاده‌سازی و آزمایش شوند.
- تدوین ویدئو می‌تواند با ابزارهای محلی متن‌باز مانند FFmpeg توسعه یابد؛ تبدیل گفتار به متن محلی نیز می‌تواند از Whisper استفاده کند. این‌ها نیازمند ادغام و تست مستقل‌اند و با واردکردن API Key به‌طور خودکار فعال نمی‌شوند.
- API رایگان تضمین دائمی، ظرفیت نامحدود یا SLA ندارد؛ خلبان باید خطای 429، 401/403، timeout، مدل حذف‌شده و سهمیه تمام‌شده را مدیریت کند.
- VPN Smart Pilot باید مستقل از در دسترس‌بودن سرویس‌های هوش مصنوعی ابری کار کند.
