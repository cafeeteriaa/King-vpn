# King VPN v8.5 — Smart Pilot UI

مخزن سورس King VPN برای کار با GitHub و ساخت اندروید از طریق GitHub Actions.

> **وضعیت:** این مخزن سورس برنامه و اسکریپت تولید پروژه Flutter/Android را نگه می‌دارد. فایل APK از قبل داخل مخزن نیست؛ workflow آن را در GitHub Actions می‌سازد.

## ویژگی‌های بسته

- حفظ ابزارها و اسکنرهای موجود در سورس ارسالی؛ از جمله DNS، IP، SNI، پورت، نت ملی، سرور شخصی، خرید سرور، کانال‌های تلگرامی، Cloudflare/CDN، Reality و WebSocket.
- حذف فقط سه کاشی ابزار از صفحه ابزارها: «پروفایل‌ها»، «حالت شبکه» و «تست کامل خودکار». تب ناوبری پایین صفحه و سایر صفحات/ماژول‌ها حذف نشده‌اند.
- فقط یک کنترل اصلی «خلبان هوشمند» وجود دارد؛ همین کنترل شروع/توقف اتصال را مدیریت می‌کند و راهبرد داخلی یا جهانی را بر اساس شواهد شبکه درون همان نشست انتخاب می‌کند. حالت نامشخص باعث حدس یا گزارش موفقیت ساختگی نمی‌شود. ابزارهای دستی و پوشه‌های پروتکل حفظ شده‌اند. ترمیم کد اجرایی از مسیر امن گزارش/پچ/CI انجام می‌شود، نه با بازنویسی APK نصب‌شده.
- رنگ‌بندی تجاری متعادل بر پایه گرافیت متوسط، آبی خاکستری و طلایی مات؛ از رنگ‌های تند و رنگین‌کمانی در اجزای اصلی رابط پرهیز شده است.

## هوش مصنوعی محلی و مهندس کد

- مدل کدنویس Qwen2.5-Coder-1.5B-Instruct Q4_K_M با موتور llama.cpp روی گوشی اجرا می‌شود؛ برای دانلود اولیه حدود 1.12 GB فضا لازم است و مدل داخل APK نیست.
- مدل با SHA-256 و اندازه دقیق اعتبارسنجی می‌شود؛ اجرا فقط روی Android API 28+ و دستگاه arm64 با فرایند 64-bit پشتیبانی می‌شود. حداقل‌های حافظه/فضا قبل از دانلود کنترل می‌شوند.
- هوش مصنوعی می‌تواند از Google برای پیدا کردن مستندات رسمی استفاده کند، صفحات مجاز را بخواند و منبع/تاریخ را در حافظه تحقیق محلی ذخیره کند. این روش از HTML جست‌وجوی عمومی استفاده می‌کند و ممکن است با محدودیت Google موقتاً در دسترس نباشد.
- برای نوشتن در GitHub، کاربر باید یک Fine-grained token با دسترسی Contents و Pull requests را در صفحه هوش مصنوعی ذخیره کند. توکن در Android secure storage نگهداری می‌شود.
- عامل فقط در فایل‌های محدود `lib/`، `test/` و `tools/` پیشنهاد تغییر می‌سازد؛ شاخه جدا و Pull Request ایجاد می‌کند. merge خودکار و تغییر مستقیم شاخه اصلی فعال نیست.
- این مدل کوچک موبایلی است و نباید با مدل‌های بزرگ ابری هم‌سطح فرض شود. حافظه تحقیق به معنی آموزش مجدد وزن‌های مدل نیست. چرخه خودکار خواندن خطای CI و retry چندمرحله‌ای هنوز در حال توسعه است.

جزئیات و محدودیت‌های فنی: [سند مهندس هوش مصنوعی](docs/KING_AI_SOFTWARE_ENGINEER_FA.md).

## ساخت APK در GitHub

1. یک repository در GitHub بساز و محتویات این پوشه را در ریشه repository بارگذاری کن.
2. از تب **Actions**، گردش کار **King VPN Android CI** را انتخاب کن.
3. روی **Run workflow** بزن؛ همچنین push به شاخه `main` یا `master` و Pull Request باعث اجرای خودکار می‌شود.
4. پس از پایان موفق، در بخش **Artifacts** فایل APK بهینه‌شده در حالت Release برای arm64 با نام `king-vpn-arm64-release-*` و آرشیو کامل سورس به‌همراه میزبان Flutter/Android تولیدشده با نام `king-vpn-full-source-*` را دریافت کن.
5. برای بازکردن پروژه کامل در Android Studio، ZIP سورس را استخراج و پوشه‌ی `build_app/` را باز کن. پوشه‌ی ریشه نیز سورس اصلی، تست‌ها و اسکریپت‌های آماده‌سازی را نگه می‌دارد.

این workflow برای ساخت APK آزمایشی به کلید امضای شخصی نیاز ندارد. APK خروجی در حالت Release و برای arm64 ساخته می‌شود، اما با کلید debug تولیدشده در CI امضا می‌شود و نسخه production-signed یا فروشگاهی نیست. برای انتشار رسمی، workflow جداگانه‌ی `King VPN Signed Android Release` با تگ نسخه‌ی `vMAJOR.MINOR.PATCH` اجرا می‌شود؛ این workflow به keystore و GitHub Secrets مالک پروژه نیاز دارد و پس از اعتبارسنجی، APK امضاشده و SHA-256 را در GitHub Release منتشر می‌کند. کلیدها و رمزهای امضا را هرگز داخل Git قرار نده.

## ساخت محلی

نیازمندی‌ها: Flutter stable، Android SDK، Java 17 و Python 3.

اسکریپت workflow ابتدا یک میزبان Flutter اندروید در `build_app/` تولید می‌کند، سورس `lib/` را در آن کپی می‌کند، وابستگی‌ها را نصب می‌کند و سپس `prepare_android.py` و `patch_plugin.py` را اجرا می‌کند. برای اجرای همان مسیر در محیط محلی، مراحل متناظر workflow را دنبال کن.

## ساختار مهم

- `lib/` — سورس Dart برنامه و ابزارها
- `android_src/` — فایل‌های اختصاصی Android/Java/Kotlin که در مرحله آماده‌سازی کپی می‌شوند
- `plugin_source_reference/` — سورس مرجع پلاگین ارسالی برای بررسی؛ در زمان build به‌عنوان جایگزین خودکار dependency استفاده نمی‌شود
- `test/` — تست‌های واحد موجود
- `.github/workflows/build.yml` — ساخت خودکار APK در GitHub Actions
- `prepare_android.py` — آماده‌سازی Manifest، Gradle و فایل‌های Native
- `patch_plugin.py` — اصلاح سازگاری پلاگین V2Ray در محیط build

## معماری خلبان هوشمند ∞ و خودترمیمی

- مسیر اتصال موجود Xray/V2Ray حفظ شده است؛ هیچ هسته‌ی اضافی یا placeholder مربوط به موتور دوم در این نسخه نگهداری نمی‌شود.
- `lib/network_health.dart` سلامت Domestic و Global را جدا نگه می‌دارد؛ قطع اینترنت جهانی به‌تنهایی سلامت مسیر داخلی را باطل نمی‌کند. خلبان و watchdog برای حالت ملی از مقصدهای داخلی استفاده می‌کنند.
- `lib/self_repair_policy.dart` سیاست تعمیر امن، rollback و دروازه پذیرش Patch کد را تعریف می‌کند. برنامه نصب‌شده سورس اجرایی خود را درجا بازنویسی نمی‌کند.
- `tools/diagnose_build.py` گزارش خطاهای build را برای تشخیص ریشه‌ای آماده می‌کند؛ CI هنگام شکست، artifact عیب‌یابی تولید می‌کند. `lib/errjournal.dart` نیز گزارش runtime محدود و پاک‌سازی‌شده از لینک کانفیگ/شناسه/credential می‌سازد.
- `tools/patch_gate.py` ساختار Patchهای پیشنهادی را از نظر مسیرهای خطرناک، فایل‌های محافظت‌شده، افشای secret و اندازه تغییر بررسی می‌کند.
- `docs/KING_AI_SOFTWARE_ENGINEER_FA.md` معماری هدف مهندس نرم‌افزار خودمختار و وضعیت واقعی اجزای پیاده‌سازی‌شده/باقی‌مانده را مشخص می‌کند.
- `tools/repair_orchestrator.py` Patch پیشنهادی را فقط در یک کپی موقت اعمال می‌کند و پس از تست، تحلیل ایستا و بیلد موفق، آن را به‌عنوان Patch تأییدشده صادر می‌کند؛ سورس اصلی را تغییر نمی‌دهد.
  نمونه اجرا: `python3 tools/repair_orchestrator.py --patch candidate.patch --output verified-repair.patch`. این فرمان به Git و Flutter SDK نیاز دارد.
- نقشه کامل نیازمندی‌ها و معیارهای پذیرش در `docs/KING_VPN_INFINITY_ROADMAP_FA.md` است؛ وضعیت واقعی تغییرات و محدودیت‌های تست در `docs/IMPLEMENTATION_STATUS_FA.md` ثبت می‌شود.

## خلبان چندارائه‌دهنده King AI و تنظیم کلیدها

- گفت‌وگوی کینگ اکنون یک خلبان ارائه‌دهندگان جدا از خلبان شبکه VPN دارد؛ Gemini، Groq، Mistral، OpenRouter Free و Cloudflare Workers AI را با کلیدهای اختیاری امتحان می‌کند و در صورت محدودیت یا قطعی به گزینه بعدی و سپس مدل محلی برمی‌گردد.
- کلیدها در خود برنامه، صفحه «گفت‌وگوی آزاد با کینگ»، زیر کادر نوشتن پیام و داخل «راهنمای کامل King VPN و King AI» وارد می‌شوند. هر کلید را در فیلد مربوط به همان سرویس قرار بده و «ذخیره امن کلیدها» را بزن. Cloudflare علاوه بر توکن، Account ID نیز لازم دارد.
- کلیدها با Android Secure Storage نگهداری می‌شوند؛ هرگز آن‌ها را در چت، سورس، APK یا GitHub قرار نده.
- استفاده ابری با گزینه «اجازه استفاده از ارائه‌دهندگان ابری رایگان» و با رضایت کاربر فعال می‌شود؛ در حالت خاموش، مسیر محلی حفظ می‌شود.
- خلبان ارائه‌دهندگان فقط پاسخ گفت‌وگویی می‌دهد و حق تغییر VPN یا نوشتن در مخزن را ندارد. خلبان شبکه VPN مستقل و محلی باقی می‌ماند.
- جزئیات مدل‌ها، سهمیه‌ها، حریم خصوصی، مراحل دریافت کلید و محدودیت‌های چندرسانه‌ای در [راهنمای کامل فارسی ارائه‌دهندگان King AI](docs/KING_AI_FREE_PROVIDER_GUIDE_FA.md) و درون خود برنامه آمده است.

## نکات مهم پیش از انتشار

- آخرین نتیجه‌ی ثبت‌شده در GitHub Actions، اجرای شماره‌ی 1210 با موفقیت است: 122 تست Python/source guard، `flutter test`، `flutter analyze` و ساخت APK Release-mode برای arm64 همگی موفق شدند. APK خروجی 122,754,686 بایت (117.07 MiB) و SHA-256 آن `c729f0d8faf6da3deed2786ee4755f4614357bab1fa7919b147d519e10d1081b` است. این نتیجه، تست نصب/اتصال روی گوشی واقعی یا آزمون اپراتورهای ایران نیست. نتیجه‌ی اجرای جدیدتر را در GitHub Actions بررسی کن.
- بعضی قابلیت‌ها به سرویس‌های بیرونی، حساب Cloudflare، سهمیه ارائه‌دهندگان یا تنظیمات سمت سرور وابسته‌اند؛ «نامحدود» بودن از طرف اپ تضمین نمی‌شود.
- فایل‌های `plugin_source_reference/` برای ممیزی و مرجع‌اند؛ مجوز و شرایط بازتوزیع وابستگی‌ها را پیش از انتشار عمومی بررسی کن.
- این مخزن مجوز استفاده/بازنشر جداگانه‌ای اعطا نمی‌کند؛ حقوق سورس متعلق به صاحب آن است مگر اینکه مجوز مستقلی اضافه شود.
- قبل از عمومی‌کردن repository، کلیدهای API، توکن‌ها، آدرس‌های خصوصی و اطلاعات سرور را از سورس و تاریخچه Git پاک‌سازی کن.
